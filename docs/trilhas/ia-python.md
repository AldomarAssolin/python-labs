# Trilha: IA com Python

Esta trilha registra minha evolução em IA com Python e se apoia em dois materiais ja existentes no repositorio:

- [Cronograma de Aprendizado de IA com Python](../referencias/Cronograma_de_Aprendizado_de_IA_com_Python_para_An.pdf)
- [Prompt para IA: Tutor de Aprendizado de IA com Python](../referencias/Prompt_para_IA__Tutor_de_Aprendizado_de_IA_com_Pyt.pdf)

## Objetivo

Aprender a modelar e criar aplicacoes de Inteligencia Artificial utilizando Python, com foco em pratica, consistencia e construcao de portfolio.

## Metodo

Uso o prompt de tutor existente como apoio para uma abordagem modular:

- apresentar o cronograma geral;
- estudar os modulos sequencialmente;
- explicar conceitos de forma concisa;
- usar exemplos de codigo Python;
- propor exercicios e desafios;
- conectar os topicos com aplicacoes praticas;
- consolidar projetos no GitHub.

## Modulos do cronograma

| Modulo | Tema | Duracao prevista |
| :-- | :-- | :-- |
| 1 | Fundamentos de Python para IA | 2-3 semanas |
| 2 | Matematica e Estatistica Essenciais | 2-3 semanas |
| 3 | Manipulacao, Analise e Visualizacao de Dados | 3-4 semanas |
| 4 | Machine Learning | 4-5 semanas |
| 5 | Deep Learning | 4-5 semanas |
| 6 | MLOps e Implantacao | 2-3 semanas |
| 7 | Projetos e Portfolio | continuo |
