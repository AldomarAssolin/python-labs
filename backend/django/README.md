# Backend com Django

## Regra de organizacao

Este diretorio recebe conteudo quando houver evidencia concreta de estudo ou implementacao. Mantenho a estrutura enxuta para preservar clareza e organização.

## Relacao com o Python Labs

Django entra no repositorio como competencia de Backend. Registro a trilha de acompanhamento em [../../docs/trilhas/django-master.md](../../docs/trilhas/django-master.md).
