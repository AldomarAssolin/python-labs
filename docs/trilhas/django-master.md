# Trilha: Django Master

Esta trilha reserva meu espaço de estudo de Django dentro do Python Labs sem reorganizar o repositorio por curso, professor ou plataforma.

## Objetivo

Registrar laboratorios e evidencias de Backend com Django usando minha regra de evolução:

> Conteudo -> laboratorio -> desafio -> aplicacao -> evidencia

## Como registrar estudos

Quando fizer sentido, cada topico estudado deve gerar:

- uma anotacao objetiva do conceito;
- um laboratorio pequeno e executavel;
- um desafio com entrada e saida verificaveis;
- uma aplicacao ou incremento de aplicacao;
- uma evidencia no README do respectivo diretorio.
